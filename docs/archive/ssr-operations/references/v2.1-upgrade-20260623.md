## 三项新功能

### Gate prompt 配置化
- `_call_llm_intent(gate_prompt)` — 读取 `intent_gate.prompt`
- 空 → 默认英文: "Does this user message need an AI skill? Answer only YES or NO."
- 两处硬编码 prompt 替换为变量

### 元对话检测
- `_intent_gate` 内 `meta_detection` 层
- 7 条正则，零 token
- 任务动词安全阀（复用噪音过滤的 _TASK_VERBS）
- `enabled: false` 默认关

### 自循环学习 (stub)
- `boost_skill(name)` — 公开 API
- `preferences.json` — 持久化
- `_SESSION_RECOMMENDED` — 会话内追踪
- `_format_recommendation` 产出时自动记录

## 踩坑

### hermes config set 存 JSON 数组为字符串
`hermes config set ssr.meta_detection.patterns '["...", "..."]'` → patterns 变成单行 JSON 字符串而非 YAML 列表。修复：execute_code 内用 yaml.dump 直写。

### grep 审计含 CHANGELOG/README
`grep -rn 'v[0-9]\.[0-9]' *.py *.yaml *.md` → 38 条命中，20+ 条来自历史版本表。修复：排除 CHANGELOG 和 README。
