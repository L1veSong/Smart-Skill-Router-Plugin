# v2.3.0 级联配置加载故障诊断

**会话日期:** 2026-07-23
**影响版本:** SSR v2.2.0 → v2.3.0
**根因:** `hermes_cli.config.load_config()` 在某些运行时返回空 `ssr` 节 `{}`

## 故障现象

全部子系统同时降级，日志零错误：

| 子系统 | 期望 | 实际 | 后果 |
|--------|------|------|------|
| embedding.provider | siliconflow | ollama | B 层全部"向量获取失败" |
| confidence_threshold | 0.62 | 0.40 | 测试期望值脱节 |
| auto_gen_rules | False | True | 明明 config 关了，重启复活 |
| b_layer.api_key | (主模型 key) | "" | LLM 筛查 HTTP 401 |
| intent_gate | 正常 | 部分正常 | 它做了 key 继承，没全死 |

## 根因

```python
# 旧版（v2.2.0）——单路径，无回退
def _load_ssr_config() -> dict:
    try:
        from hermes_cli.config import load_config
        raw = load_config()
        cfg = raw.get("ssr", {})  # ← 这里返回 {} 时全线降级
    except Exception:
        cfg = {}
    return cfg
```

`hermes_cli.config.load_config()` 是平台配置读取函数，依赖 session context / profile / env vars。在某些运行时（如测试环境、cron 执行、非标准启动路径），它可能返回不完整或不正确的 dict。**问题不是函数报错（有 try/except），而是它静默返回空 dict。**

## 修复

### 1. 双路径读取（`_load_ssr_config()`）

```python
def _load_ssr_config() -> dict:
    cfg = {}
    # 路径 1: hermes_cli（支持环境变量合并）
    try:
        from hermes_cli.config import load_config
        cfg = load_config().get("ssr", {}) or {}
    except Exception:
        cfg = {}
    # 路径 2: PyYAML 直读（hermes_cli 拿不到时）
    if not cfg:
        try:
            import yaml
            with open(Path.home() / ".hermes" / "config.yaml") as f:
                cfg = yaml.safe_load(f).get("ssr", {}) or {}
        except Exception:
            cfg = {}
    return cfg
```

### 2. 安全性默认值加固（`_auto_gen_enabled()`）

```python
# 旧: return cfg.get("auto_gen_rules", True)  ← 读不到 config 就开
# 新: return cfg.get("auto_gen_rules", False) ← 读不到 config 不开
```

### 3. api_key/base_url 继承（`_llm_screen()` / `_call_llm_screen_direct()`）

`b_layer.api_key` 为空 + provider=main 时，从主模型继承：
```python
api_key = bl.get("api_key", "")
if not api_key:
    mc = _load_main_model_config()
    api_key = mc.get("api_key", "")
    base_url = mc.get("base_url", "") or base_url
```

### 4. test_ssr.py embedding 分支补全

旧代码 `_embed_text()` 只处理 ollama provider，新增完整 siliconflow 调用路径。

## 诊断口诀

> **B 层全死 + 阈值不对 + auto-gen 复活 → 先查 `_load_ssr_config()` 是否拿到空 dict**

三步验证：
```bash
cd ~/.hermes/plugins/ssr
python3 -c "
import __init__; __init__._CONFIG_CACHE = None
from __init__ import _load_ssr_config
cfg = _load_ssr_config()
print('empty' if not cfg else f'ok: {len(cfg)} keys')
"
```

返回 `empty` → 根因确认。用 PyYAML 回退路径修复。
