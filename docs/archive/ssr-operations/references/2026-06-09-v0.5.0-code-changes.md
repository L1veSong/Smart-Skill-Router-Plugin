## 降级链

```
embedding 可用 → embedding 匹配（主力，Top-30）
        ↓ 不可用
关键词匹配 → _match_a_layer_keyword（fallback）
        ↓ 关键词也不可用
B 层 LLM → _match_b_layer（兜底）
```

## 关键设计决策

1. **A 层关键词 cap 保持 5**：准确率 10%，去上限 = 噪音轰炸。去上限在 embedding 和 B 层生效。
2. **多后端 embedding**：和 B 层一样，ollama(默认)/siliconflow(免费)/openai(付费)。开源用户零配置。
3. **Embedding 索引持久化**：`embeddings.json`，重启时增量同步，不需要每次重建。
