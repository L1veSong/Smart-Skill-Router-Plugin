# SSR v2.0.0 变更日志（2026-06-22）

## 架构变更

- A层规则解耦：v2(硬编码skill名) → v3(keywords运行时匹配SKILL_INDEX)
- B层兜底恢复：A层无候选时LLM独立匹配（`_call_llm_screen_direct`）
- 意图门控弃用：embedding已是零成本门控
- 降级链简化为：噪音白名单→embedding→LLM(1次)

## a_rules.json v2→v3

- 格式：`{regex: {skills: [{name,phase}]}}` → `{regex: {keywords: [...], phases: [...]}}`
- 108条规则迁移完成，停用词过滤
- 3条顺序敏感正则改lookahead

- `_match_a_layer_keyword`：skills遍历 → keywords动态匹配SKILL_INDEX
- `_pre_llm_call`：新增无候选LLM独立匹配路径

- plugin.yaml：0.7.0 → 2.0.0
- __init__.py：2077行，新增约48行
