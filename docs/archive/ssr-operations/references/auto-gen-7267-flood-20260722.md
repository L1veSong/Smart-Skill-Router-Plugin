## 根因

`_auto_gen_a_rules()` 第 907 行生成规则时缺 `skills` 字段：
```python
rules[pattern] = {
    "keywords": [kw],
    "source": "auto-gen",
    # ❌ 缺 "skills": [name] 字段
}
```

## 双门禁问题

SSR 有两个独立的自动生成路径，PROMOTE_THRESHOLD 只挡了一个：

| 路径 | 触发时机 | PROMOTE_THRESHOLD | config 控制 |
|------|---------|:--:|:--:|
| `_promote_to_a()` | 运行时 B→A 升级 | ✅ 拦截 | — |
| `_auto_gen_a_rules()` | 重启时启动触发 | ❌ 不检查 | `ssr.auto_gen_rules` |

## 回滚后二次污染

**症状：** 回滚 a_rules.json 到备份后，下次 Hermes 重启时再次被污染到 7200+ 条。

**根因：** 回滚和关 auto_gen 的顺序错了。正确顺序：
```
1. hermes config set ssr.auto_gen_rules false   ← 先关开关
2. cp 备份 → a_rules.json                       ← 再回滚
3. 重启 Hermes                                  ← 安全
```

如果顺序反过来（先回滚再关），重启瞬间 `_auto_gen_a_rules()` 会再次生成垃圾。

## 完整恢复步骤

```bash
# 1. 关 auto_gen（最重要！）
hermes config set ssr.auto_gen_rules false

# 2. 确认生效
grep 'auto_gen_rules' ~/.hermes/config.yaml  # 应为 false

# 3. 回滚 a_rules.json
cp ~/.hermes/plugins/ssr/a_rules.json.bak.07222130 ~/.hermes/plugins/ssr/a_rules.json

# 4. 验证：文件应 < 10KB，所有规则有 skills
python3 -c "
import json
with open('$HOME/.hermes/plugins/ssr/a_rules.json') as f:
    rules = json.load(f)
empty = sum(1 for v in rules.values() if not v.get('skills'))
assert empty == 0, f'{empty} 条空 skills'
assert len(rules) < 100, f'{len(rules)} 条 — 未被污染'
print(f'OK: {len(rules)} 条，全有 skills')
"

# 5. 重启 Hermes 以加载新规则
```
