## 诊断方法论教训

**三级误判链：**
1. `grep 'LLM 筛查 HTTP 404' | tail -1` → 返回上一会话残留 → 误判当前 B 层故障
2. 直接读代码分析 URL 构造 → 代码实际已修复（`.removesuffix('/v1')`）→ 浪费时间
3. Python 测试中截断 API key（`sk-7c6...5711` 含字面 `...`）→ 假 401 → 误判 key 过期

**正确顺序（铁律）：直测 API → 读代码 → 看日志。不可反。**
