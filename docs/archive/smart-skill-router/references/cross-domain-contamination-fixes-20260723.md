# 跨域正则污染修复记录 (2026-07-23)

v2.5.0 域扩张 (16→32域) 中暴露的跨域污染模式。

## 污染类型

### 类型A: 裸词捕获 (单字/双字动词无上下文)

| 裸词 | 误中域 | 正确域 | 修复 |
|------|--------|--------|------|
| `验证` | code-quality | planning | 加后缀: `验证.*(?:完成\\|结果\\|通过)` |
| `生成` | 视频 | china-services | 加负向断言: `(?!.*(?:图片\\|照片\\|画))` |
| `整理` | storage | obsidian | storage 去 `整理`,只留 `清理.*(?:会话\\|记忆)` |
| `吃` | travel | macos | travel 去裸 `吃`,只留 `美食\\|小吃\\|好吃.*(?:店\\|馆)` |
| `规划` | planning | travel | planning 加前缀: `制定.*规划` 非 `自驾规划` |

### 类型B: 域归属错误

| 规则 | 误归属 | 正确归属 |
|------|--------|---------|
| `macos-disk-cleanup` | 部署 | macos |
| `清理.*[Mm]ac` | 部署 | macos |

### 类型C: 强制后缀导致漏匹配

| 正则 | 问题 | 修复 |
|------|------|------|
| `表情包.*搜` | 强制要求 `搜` 后缀,`找个表情包` 漏过 | 改为 `表情包` |
| `原型.*(?:做\\|开发)` | `快速做个原型验证` 中 `验证` 被 code-quality 先捕获 | 加 `快速.*原型` |

## 修复方法论

每新增一条正则后:

1. **同域互斥检查** — 同域内已有规则不应同时命中同一输入
2. **邻域交叉检查** — 对每个相邻域的核心词跑交叉测试
3. **噪音检查** — 闲聊/问候/确认词不应命中任何域
4. **裸词审计** — 单字/双字动词必须加前后缀上下文
