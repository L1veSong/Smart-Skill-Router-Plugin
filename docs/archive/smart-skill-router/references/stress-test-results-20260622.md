# SSR 极限测试 v2.0.0 (2026-06-22)

## 方案确定

三方案实测对比：
- 当前管线(emb→LLM筛): 38%
- 纯LLM一次: 54%  
- **LLM+emb提示: 85%** ← 最优

纯 LLM(DeepSeek v4-pro, 1M上下文)频繁判 NO_NEED — 不是信息过载，是无 embedding 上下文锚点导致 prompt 释义漂移。

## 测试条件

- 模型: DeepSeek v4-pro
- Embedding: bge-large-zh-v1.5 (1024维, Ollama)
- Skill: 218 已安装
- 用例: 51条, 覆盖15类目

## 结果

### 全量 (51条)
- 准确率: 80% (41/51)
- 噪音拦截: 9/9 (100%)
- 推荐命中: 32/42 (76%)
- 漏过: 10

### 噪音 (9条)
全拦截。9条正则白名单+LLM意图判断双层防护。
