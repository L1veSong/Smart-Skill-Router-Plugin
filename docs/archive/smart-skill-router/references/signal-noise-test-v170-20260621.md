## 回归根因

v1.6.4 解锁 embedding 门控（`keyword_result and` → `if _EMBEDDING_INDEX:`）后，embedding 每条消息必跑。用户消息"极大的退步。分析原因"触发 paper-spine-* 洪水——"分析"关键词命中后 embedding 在 387 skill 里扫 top-30，11/30 不相关。

三层叠加：LLM门控0/5漏过 → A层auto-gen规则太宽 → embedding裸奔噪音。

## 修复

1. **embedding关键词锁**：`_match_a_layer` 关键词未命中→直接 return None，embedding 不跑。embedding 只做放大器，不做独立噪声源。
2. **噪音白名单**：10条中文正则（嗯/谢谢/好的/你觉得呢/天气/哈哈/纯标点），调 LLM 之前直拦，零 token。
3. **死引用自动清理**：`_cleanup_a_rules()` 启动扫描 + `_hot_remove_skill()` 热删除联动。
4. **空规则保留**：清理后空规则不删除，保留作关键词意图信号。
