# B→A 自学习 v2→v3 格式修复

2026-06-22：`_promote_to_a` 存储 v2 格式 `{skills: [{name, phase}]}` → `_match_a_layer_keyword` 只读 v3 `{keywords: [...]}` → 升级规则废掉。

**修复（最终版）：从 regex pattern 提取关键词，不拆 skill 名。**
```python
# 移除 regex 语法，保留字面量
import re
parts = re.split(r'[\|\(\)\.\*\+\?\^\[\]\{\}]', pattern)
for part in parts:
    part = part.strip()
    if len(part) >= 2:
        keywords.append(part.lower())
keywords = list(set(keywords))[:12]

_A_RULES[pattern] = {
    "keywords": keywords,
    "phases": phases,
}
```

**为什么不拆 skill 名：** 用户消息里的词才是会重复出现的（"小红书"→"xiaohongshu"）。拆 skill 名得到的是泛词（"agent", "reach"），没有匹配价值。

**影响：** 修复前 B 层匹配到的 skill 永远不会被 A 层学习。修复后 B→A 连续 3 次命中 → 自动固化，关键词来自用户实际输入。
